# Scan2Score
Scan2Score is an AI-powered tool that digitizes and analyzes exam papers to provide quick, meaningful feedback on student performance. The system converts scanned question papers and answer sheets into clean, machine-readable text using OCR (Optical Character Recognition) and uses an LLM to understand both the question and the student's response.
Scan2Score focuses on evaluating the quality and relevance of each answer. It generates clear, constructive feedback on how well the student addressed the question, identifies missing concepts, and highlights areas that need improvement.

By automating the extraction, interpretation, and feedback process, Scan2Score reduces the workload for teachers, accelerates evaluation, and helps students understand their strengths and weaknesses more effectively — all with a simple scan-and-upload workflow.
